# Planejai

> Um planejador financeiro pessoal desenvolvido para ajudar no controle e na organização das finanças.

## Sobre o projeto

O Planejai é uma aplicação web desenvolvida para facilitar o planejamento financeiro pessoal.

A proposta é permitir que o usuário informe sua situação financeira e receba uma simulação organizada, acompanhada de insights para auxiliar na tomada de decisões.

O projeto também possui histórico das simulações realizadas.

## Funcionalidades

- Simulação financeira
- Cálculo e organização das informações financeiras
- Geração de insights com IA
- Histórico de simulações
- Tema claro e escuro
- Interface responsiva
- Armazenamento local das simulações

## Tecnologias

- React
- JavaScript
- Vite
- Tailwind CSS
- React Router
- API de IA
