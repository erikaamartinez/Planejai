# Planejai

Aplicação web para organização de estudos e planejamento pessoal.

## Tecnologias

- React
- Vite
- JavaScript
- Tailwind CSS

## Sobre o projeto

O Planejai é um projeto desenvolvido para praticar desenvolvimento front-end e criar uma ferramenta pessoal de organização dos estudos.

## Como executar

```bash
npm install
npm run dev
